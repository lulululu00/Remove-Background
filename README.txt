白底去背工作台 — 發布說明

這個資料夾就是完整的網站，放上任何「靜態網頁空間」就能用，不需要伺服器程式。

【最快的方法：Netlify Drop（免費、免寫程式）】
1. 用電腦瀏覽器打開 https://app.netlify.com/drop
2. 把整個「whitebg」資料夾拖進網頁
3. 等上傳完成（約 90 MB），會得到一個網址，例如 https://xxxx.netlify.app
4. 註冊 / 登入 Netlify 帳號，網站才會一直保留；也可以在設定裡改成好記的網址名稱

其他也可以用：Cloudflare Pages（直接上傳資料夾）、GitHub Pages。

【大家怎麼用】
- 用 Chrome 或 Edge 打開網址就能用，圖片只在使用者自己的電腦裡處理，不會上傳。
- 第一次開啟會下載約 88 MB 的 AI 模型，之後會存在瀏覽器裡。
- 建議用電腦；需要瀏覽器的「硬體加速」開啟。

【安裝成 App】
- 電腦 Chrome / Edge：打開網址後，網址列右側會出現「安裝」圖示，按下去就會變成桌面 App。
- iPhone：用 Safari 打開 →「分享」→「加入主畫面」。
- Android：Chrome 選單 →「安裝應用程式」或「加到主畫面」。

【之後要更新】
把新版的檔案重新拖上去覆蓋即可。

注意：一定要用網址（https://）開啟，直接在電腦上雙擊 index.html 開啟時，AI 模型會因為瀏覽器的安全限制而無法載入。
